# sixl.org

Persönliche Website von Daniel Sixl, umgesetzt mit Quasar 2, Vue 3 und Vite.

## Voraussetzungen

- Node.js 24
- npm 10 oder neuer

## Installation

```sh
npm ci
```

## Entwicklung

```sh
npm run dev
```

## Build

```sh
npm run build
```

Die fertige Website liegt unter `dist/spa`.

## Build lokal ansehen

```sh
npm run preview
```
